## 分层原则

| 层 | 目录 | 职责 | 依赖方向 |
|----|------|------|----------|
| 展示层 | `app/` | Streamlit 页面 UI 渲染、用户交互 | → 核心逻辑层 |
| 核心逻辑层 | `src/` | 数据处理、模型训练、预测推理 | → 外部资源 |
| 外部资源 | `data/`、`models/` | 静态数据与模型持久化 | 无依赖 |

### 硬约束

- `app/` 不得直接读写文件或操作 pandas DataFrame 复杂逻辑，必须通过 `src/` 调用
- `src/` 不得引用 Streamlit API（`st.*`），保持纯逻辑可测试
- `config.py` 是所有常量的唯一来源

## 配置管理

所有可配置项集中在 `src/config.py`，按类别组织：

```python
# 路径配置
DATA_DIR = Path("data")
MODEL_DIR = Path("models")
MODEL_FILE = MODEL_DIR / "best_model.pkl"
PREPROCESSOR_FILE = MODEL_DIR / "preprocessor.pkl"

# 数据配置
TARGET_COL = "y"
TEST_SIZE = 0.2
RANDOM_SEED = 42

# 模型配置
MODEL_CANDIDATES = ["logistic", "random_forest", "xgboost"]
```

## 页面路由

Streamlit 使用 `pages/` 目录自动路由：

```text
app.py                    # 入口 → 自动重定向或作为首页
pages/
├── 1_📊_数据分析.py       # page_analysis
└── 2_🔮_在线预测.py       # page_prediction
```

> 或采用自定义侧边栏导航方式，配置在 `app.py` 中。
